# Contributing

Open an issue describing the problem or proposed change, then submit a focused pull request. Explain the user-visible behavior and relevant validation.

Use Node.js 22 or later, configure your own `.env` from `.env.example`, and run `npm run check` and `npm test` before submitting. Regression tests should isolate paid APIs and production databases.

Never commit API keys, passwords, session secrets, database exports or personal data. Report sensitive issues according to SECURITY.md.
