# Security

Do not post credentials or exploit details in public issues. Use GitHub's private vulnerability reporting feature when enabled on this repository. Otherwise contact the repository owner privately through an existing trusted channel.

If a secret is exposed, revoke or rotate it at its provider. Removing a file or replacing Git history cannot revoke a credential or erase copies already downloaded.

See docs/DEPLOYMENT.md for HTTPS, browser sandboxing, network egress and registration abuse controls. This project has automated regression tests; it has not undergone an independent security audit.
